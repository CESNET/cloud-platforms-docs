with active accounts via the identity federations.

## Project Types

Resources on the Oliver cloud are allocated exclusively via **group projects**, which come in two flavors:

* __non-sensitive group project__,
* __sensitive group project__.

<Callout type="info" title="No personal projects on Oliver">
	Unlike the G2 Brno and G2 Ostrava clouds, the Oliver cloud does not provide personal projects.
	If you need a low-barrier entry into the infrastructure for testing and exploration of features,
	use the [G2 Brno](../brno-g2-site/get-access) or [G2 Ostrava](../ostrava-g2-site/get-access) cloud.
</Callout>

### Non-sensitive Group Project

Non-sensitive group projects are equivalent to group projects on the previous OpenStack clouds
(G2 Brno and G2 Ostrava) and are suitable for the vast majority of workloads.

### Sensitive Group Project

Sensitive group projects are intended for data that requires a higher level of confidentiality in the sense of the
ISO 27000 family of standards — data that must not be easily accessible and whose leakage would pose a problem,
such as personal data or unpublished research results.

Sensitive projects are subject to stricter security rules:

* a VM backup must be defined,
* no plaintext external or internal traffic,
* additional rules will be published.

## Group Project

Group projects are the primary resource allocation unit for MetaCentrum Cloud.
Any user or a group of users requiring a non-trivial amount of resources must
request a group project using [this form](https://projects.brno.openstack.cloud.e-infra.cz/create.php) and provide the following basic information:

* __name of the project__,
* __purpose of the project__,
* __contact information__,
* __amount and type of requested resources__,
* __impact would the service have on unavailability for 1h, 1d, 1w__,
* __estimated length of the project__,
* __project manager (project invertigator)__,
* __project organization__,
* __access control information__.

## Increase Quotas for Existing Group Project

To request quota increase, access to particular [flavor](flavors) or extend project lifetime, please use [this form](https://projects.brno.openstack.cloud.e-infra.cz/update.php).
